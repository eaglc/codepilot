## 工具执行的 7 层防御

```
输入: Tool Call
  │
  ├─ 第一层: 验证工具存在 ✓
  │  └─ 工具名是否在注册表?
  │
  ├─ 第二层: 权限检查 ✓
  │  ├─ 用户权限模式 (read-only/ask/auto-edit)
  │  ├─ 文件路径验证 (在工作树内?)
  │  └─ 敏感路径保护
  │
  ├─ 第三层: 预算检查 ✓
  │  ├─ Token 预算充足?
  │  ├─ 时间预算充足?
  │  └─ 步数限制?
  │
  ├─ 第四层: 参数清理 ✓
  │  ├─ 参数有效性验证
  │  ├─ DataPolicy 清理
  │  └─ 大小限制
  │
  ├─ 第五层: 重放策略检查 ✓
  │  ├─ ReplayPolicy 一致?
  │  ├─ IdempotencyKey 存在?
  │  └─ 防止副作用重复
  │
  ├─ 第六层: 执行 ✓
  │  ├─ 调用处理函数
  │  ├─ 捕获异常
  │  └─ 流式报告进度
  │
  └─ 第七层: 结果处理 ✓
     ├─ 结果验证
     ├─ 敏感数据清理
     ├─ 输出大小限制
     └─ 保存到会话

输出: Tool Result
```
